# Excel-Data-Analytic-Project
Dataset Description
This dataset provides real-time air quality data from monitoring stations across various cities and states in India. It includes the geographic location (country, state, city, station, latitude, longitude), timestamp of the latest update, and pollutant concentration details—including pollutant type (pollutant_id) and its minimum, maximum, and average values (pollutant_min, pollutant_max, pollutant_avg).
